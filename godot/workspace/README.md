# TerraWave development workspace

The editable project is in [TerraWave-Godot-M2.12](TerraWave-Godot-M2.12/).
Development continues in that folder; the ZIP files are preserved delivery backups.

- Double-click [PLAY_TERRAWAVE.cmd](PLAY_TERRAWAVE.cmd) to run the game.
- Double-click [EDIT_TERRAWAVE.cmd](EDIT_TERRAWAVE.cmd) to open the Godot editor.
- Continue from the [development checkpoint](TerraWave-Godot-M2.12/docs/CODEX_CHECKPOINT.md).
- Run checks using the [Windows development instructions](TerraWave-Godot-M2.12/docs/WINDOWS_DEVELOPMENT.md).

The launchers use the portable Godot and FFmpeg installations in `.tools`.
If Settings already contains an explicit FFmpeg path, it still takes priority;
clear it to use automatic detection or choose the complete local FFmpeg build.
